# ATP015 — OpenTelemetry Certified Associate (OTCA)

Preparation scaffold: one stage per exam domain, connected through `path.yaml`
to a training series repository. New material is planned, and the course
registration in `astrona-content` stays **draft**.

This exam is part of the current Golden Kubestronaut requirements.

| Stage | Domain | Weight | Series |
| --- | --- | --- | --- |
| STG001 | Fundamentals of Observability | 18% | [ATS073](https://github.com/astrona-io/ATS073) |
| STG002 | The OpenTelemetry API and SDK | 46% | [ATS074](https://github.com/astrona-io/ATS074) |
| STG003 | The OpenTelemetry Collector | 26% | [ATS075](https://github.com/astrona-io/ATS075) |
| STG004 | Maintaining and Debugging Observability Pipelines | 10% | [ATS076](https://github.com/astrona-io/ATS076) |

Source: [official OTCA curriculum](https://training.linuxfoundation.org/certification/opentelemetry-certified-associate-otca/), checked 2026-10-10.
Registration: `astrona-content/courses/opentelemetry-certified-associate-otca.yaml`.
Content authors work in the stage repositories; this repository groups them.
